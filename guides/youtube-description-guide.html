What to Put in a YouTube Video Description

Learn how to write useful video descriptions with a clear summary, helpful links, chapters, and accurate context.

Write a useful opening

Use the first lines to explain what the video covers and who may find it useful. Put the most important context first instead of beginning with a long list of hashtags or generic greetings.

Summarize what actually happens

Mention the main steps, topics, products, locations, or questions covered. Keep the summary faithful to the finished video. Do not add claims, results, or endorsements that the video does not support.

Add links with context

Link to resources viewers may need, such as an official product page, source material, or another relevant video. Describe each link so viewers know where it leads, and test links before publishing.

Use chapters when they help

For longer videos, timestamps can make sections easier to find. Add them only after editing is complete, check that each timestamp lands at the right point, and use clear chapter labels.

Include credits and disclosures

Credit material where required and clearly disclose relevant sponsorships, affiliate relationships, or other commercial connections. Follow the platform’s current disclosure rules and applicable local requirements.

Keep keywords natural

Use the phrases a viewer would naturally use to describe the topic, but do not repeat them unnaturally. A readable, accurate description is more useful than a block of search terms.

Example

Example opening: “In this video, I show how to set up a beginner home recording space, including microphone placement, basic room treatment, and a short test recording.”

Keep in mind: YouTube features and description rules can change. Check current YouTube Help guidance for up-to-date requirements and formatting.
